## Assumptions adopted without routine questions

1. Level 1 defaults toward the human; level 3 substitutes a butterfly for level 2's cockroach and also defaults toward the human.
2. Raw counts use one per biological death, while weighted impact is a separate playful display using 1.0/0.1/0.2. Robot destruction is narrated but not counted as a biological death. Possible people never born are not fatalities.
3. All humans have the same death weight. No demographic or profession-based worth table exists.
4. Standard timing is 30 seconds throughout. Longer/untimed modes and Pause are legitimate accessibility features and receive identical ratings.
5. Scene actions are armed and reversible before commitment, like selecting a route; Resolve now commits early. This makes keyboard/touch handling predictable.
6. Probabilities describe uncertain evidence in fixed authored stories, not sampled gameplay. The UI explains this and hides actual realization text until resolution.
7. Stipulated later deaths count with their originating level, once, and are separately labeled. All levels are independent worlds.
8. Six schematic templates provide all visual layouts without 200 custom physics scenes. Exact facts remain readable in HTML; uncertainty is never illustrated using hidden actual counts.
9. The four lenses and all numbers are editorial. No rating is attributed to an academic source and no score blocks progression.
10. No release deployment is required. The repository is a design handoff; implementation and browser verification remain future work.
